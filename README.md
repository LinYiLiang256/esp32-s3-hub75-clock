# ESP32-S3 HUB75 64×64 全彩 LED 点阵屏

> 用 **ESP32-S3-N16R8** 驱动 **HUB75 接口 64×64 全彩 LED 单元板** 的完整工程集：
> 从"点亮测试"到"网页配网 + 网络时钟 + 音乐频谱 + 复古小游戏"。

本仓库包含两个独立子工程，按学习/使用顺序排列：

| 子工程 | 用途 | 说明 |
|---|---|---|
| [`Demo1_test`](Demo1_test/README.md) | **测试板子** | 最小入门示例：整屏 **红 → 绿 → 蓝** 每 2 秒循环点亮，用于验证接线、供电、面板是否正常。不含灰度和任何外设。 |
| [`Demo2_wifi_time_clock`](Demo2_wifi_time_clock/README.md) | **时钟工程** | 完整功能版本：WiFi 配网、网络对时、RGB444 灰度显示、**19 种表盘**（数字钟/频谱/示波器/图片/画板/表情/鱼缸/7 款小游戏），以及滚动字幕与电脑音频驱动。 |

---

## 1. 硬件要求

| 器件 | 说明 |
|---|---|
| ESP32-S3 开发板 | **N16R8**（16MB Flash + 8MB PSRAM），如 ESP32-S3-DevKitC-1 |
| HUB75 单元板 | 64×64 全彩，1/32 扫描，16 针 HUB75(E) 接口 |
| 外部 5V 电源 | **单元板必须独立供电**（≥5V/3A），不要从开发板取电 |
| USB 线 | 连接 UART 口（CH343），用于烧录、日志（Demo2 的电脑音频也走这里） |

> ⚠️ 所有 GND 必须共地：单元板 GND、外部电源 GND、ESP32 GND 连在一起。

### 接线表（两个子工程完全一致）

| HUB75 引脚 | ESP32-S3 GPIO | 说明 |
|---|---|---|
| R1 / G1 / B1 | GPIO4 / 5 / 6 | 上半屏 红/绿/蓝 |
| R2 / G2 / B2 | GPIO7 / 8 / 9 | 下半屏 红/绿/蓝 |
| CLK | GPIO10 | 时钟 |
| LAT / STB | GPIO11 | 锁存 |
| OE | GPIO12 | 使能（低电平点亮） |
| A~E | GPIO13 / 14 / 15 / 16 / 17 | 行地址 bit0~bit4 |
| GND | GND | 共地 |
| 5V | 外部 5V 电源 | 单元板电源 |

> GPIO21、GPIO39、GPIO40 被 i80 总线占用（悬空，不接面板即可）；不要占用
> GPIO19/20（原生 USB）、GPIO26~32（Flash）、GPIO33~37（PSRAM）。

## 2. 快速开始

### 2.1 准备环境

项目使用 **ESP-IDF v5.4**，每次打开新终端先导出环境变量：

```bash
. $HOME/esp/esp-idf/export.sh
```

### 2.2 先跑 Demo1 验证硬件

```bash
cd Demo1_test
make flash PORT=/dev/ttyACM0     # 编译并烧录
```

上电后整屏应每 2 秒在红/绿/蓝之间循环。**如果 Demo1 不亮或颜色异常，先按
[Demo1 的调试表](Demo1_test/README.md) 排查接线与供电**，确认硬件正常后再进 Demo2。

### 2.3 烧录 Demo2 时钟工程

```bash
cd ../Demo2_wifi_time_clock
make flash PORT=/dev/ttyACM0
```

> 首次烧录前如提示找不到目标，先执行一次 `idf.py set-target esp32s3`。

### 2.4 配网与使用

- **首次使用**：连接热点 `LED-CLOCK-SETUP`（密码 `12345678`）→ 浏览器打开 `http://192.168.4.1`；
- 选择 WiFi、输入密码、选表盘 → 保存，设备自动重启并联网；
- 之后访问设备 IP（串口日志会打印）即可进管理页面，随时切换表盘、亮度、字幕、画板。

详细说明见 [Demo2 README](Demo2_wifi_time_clock/README.md)。

## 5. 技术要点

- **显示驱动**：`LCD_CAM` i80 并行总线 + DMA，RGB444 灰度 BCM 时间片扫描（约 200Hz），双缓冲防撕裂；
- **音频**：MAX9814 → ADC1 连续采样，Goertzel 64 频带 + 降噪链；支持串口接收电脑音频；
- **中文**：24×26 点阵字库（GB2312 符号 + 一级汉字，4444 字）二进制嵌入；
- **游戏 AI**：俄罗斯方块启发式评分、贪吃蛇 BFS、吃豆人曼哈顿追击、赛车避让变道等。
