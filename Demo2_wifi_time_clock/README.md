## 2. 硬件要求

| 器件 | 说明 |
|---|---|
| ESP32-S3 开发板 | **N16R8**（16MB Flash + 8MB PSRAM），双 USB 口优先 |
| HUB75 单元板 | 64×64 全彩，1/32 扫描，16 针 HUB75(E) 接口 |
| 外部 5V 电源 | **单元板必须独立供电**（≥5V/5A），不从开发板取电 |
| MAX9814 麦克风模块 | 拾音器/频谱/示波器功能使用 |
| USB 线 | 连接 UART 口（CH343），用于烧录、日志、电脑音频 |

> ⚠️ 所有 GND 必须共地：面板 GND、外部电源 GND、ESP32 GND 连在一起。

## 3. 接线表

### 3.1 HUB75 面板（16 针）

| HUB75 引脚 | ESP32-S3 GPIO | 说明 |
|---|---|---|
| R1 | **GPIO4** | 上半屏红 |
| G1 | **GPIO5** | 上半屏绿 |
| B1 | **GPIO6** | 上半屏蓝 |
| R2 | **GPIO7** | 下半屏红 |
| G2 | **GPIO8** | 下半屏绿 |
| B2 | **GPIO9** | 下半屏蓝 |
| CLK | **GPIO10** | 时钟 |
| LAT / STB | **GPIO11** | 锁存 |
| OE | **GPIO12** | 使能（低电平点亮） |
| A | **GPIO13** | 行地址 bit0 |
| B | **GPIO14** | 行地址 bit1 |
| C | **GPIO15** | 行地址 bit2 |
| D | **GPIO16** | 行地址 bit3 |
| E | **GPIO17** | 行地址 bit4（第 16 针） |
| GND | GND | 与开发板共地 |
| 5V | 外部 5V 电源 | 单元板电源 |

### 3.2 MAX9814 麦克风

| MAX9814 | ESP32-S3 | 说明 |
|---|---|---|
| VDD | **3V3** | 模块支持 2.7~5.5V |
| GND | GND | 共地 |
| **OUT** | **GPIO2**（ADC1_CH1） | 模拟音频输出 |
| GAIN | 悬空 | 40dB 增益（接 GND=50dB，接 VDD=60dB） |
| AR | 悬空 | 攻击/释放比默认 |

> OUT 线尽量短、远离 GPIO10/GPIO11（HUB75 时钟线），减少噪声。

### 3.3 禁用引脚（不要接外设）

| 引脚 | 原因 |
|---|---|
| GPIO21、GPIO39、GPIO40 | i80 总线占用（悬空） |
| GPIO19、GPIO20 | 原生 USB |
| GPIO26~32 | Flash SPI |
| GPIO33~37 | N16R8 的 Octal PSRAM |
| GPIO0、GPIO45、GPIO46 | strapping 引脚 |
| GPIO43、GPIO44 | UART0（烧录/日志） |

| 2 | 复古数码管 | 暖橙色大数字 + 绿色日期 |

| 4 | 拾音器·环形 | 板载麦克风的 20 柱环形频谱 |
| 5 | 拾音器·横排 | 21 根柱子，冷→暖渐变，白色峰值缓落 |
| 6 | 拾音器·密集 | 64 列频带无缝频谱 |
| 7 | 显示图片 | 显示 `image/image.h` 的 64×64 图片 |
| 8 | 画板 | 显示网页画板绘制的自定义图片 |
| 9 | 示波器·李萨如 | 音频波形 XY 轨迹（电脑音频时左声道→X、右声道→Y） |
| 10 | 表情动画 | 开心/生气/惊讶/眨眼/爱心 每 3 秒循环 |
| 11 | 鱼缸 | 5 条大小鱼游动 + 水草 + 气泡，右上角显示时间 |
| 12 | 俄罗斯方块 | AI 自动游玩，game over 自动重开，右上角显示时间 |
| 13 | 贪吃蛇 | BFS 自动寻路吃苹果，吃一次换色，撞墙/撞自己重开 |
| 14 | Flappy Bird | 自动扇翅穿管道，撞管道/地面重开，顶部品红时间 |
| 15 | 坦克大战 | FC 风格自动对战，坦克对抗 + 鹰基地，顶部时间 |
| 16 | 吃豆人 | 24×24 迷宫相机跟随，幽灵追击，吃豆得分，顶部时间 |

### 音频数据源说明

- **拾音器（6/7/8）**：优先使用电脑脚本发来的音频数据，无数据时回退板载麦克风；
- **示波器（11）**：优先使用电脑波形（立体声 XY），无数据时回退麦克风波形（相位偏移模拟）；
- 电脑数据停止 1 秒后自动回退。

## 5. 网页管理页面

### 5.1 进入方式

| 场景 | 操作 |
|---|---|
| 首次使用 / 未联网 | 连接热点 **`LED-CLOCK-SETUP`**（密码 `12345678`）→ 浏览器打开 **http://192.168.4.1** |
| 已联网 | 浏览器访问**设备 IP**（串口日志会打印 `已获得 IP: x.x.x.x`），或连接热点后访问 192.168.4.1 |

### 5.2 页面功能

| 区块 | 功能 |
|---|---|
| WiFi 配置 | 扫描附近 WiFi、输入 SSID/密码、保存并连接（保存后自动重启） |
| 表盘样式 | 19 个表盘选一，**保存后立即生效** |
| 屏幕亮度 | 10%~100% 滑块（调 BCM 时间片），即时生效 |
| 拾音灵敏度 | 0~100，环境吵就调低（噪声门更严格） |
| 滚动字幕 | 输入中英文文字 → 从右往左循环滚动 |
| 画板 | 64×64 画布，点击/拖动点亮像素，10 色可选，完成后「显示到灯板」 |

### 5.3 配网流程

1. 上电后屏幕显示 SETUP 画面，热点自动开启；
2. 手机连接热点 → 打开 192.168.4.1；
3. 选择 WiFi、输入密码、选表盘 → 保存；
4. 设备自动重启并联网，之后随时可连热点修改设置。

## 6. 电脑音频驱动灯带

让电脑播放的音乐直接驱动屏幕频谱/示波器（ESP32 端不经过麦克风）。

### 6.1 原理

```
电脑脚本采集系统音频 → FFT/波形提取 → 115200 串口发给 ESP32 → 屏幕显示
```

### 6.2 Linux 运行

```bash
cd Demo2_wifi_time_clock
python3 tools/pc_audio_sender.py                 # 自动采集默认输出
python3 tools/pc_audio_sender.py --port /dev/ttyACM0 --gain 1.2
```

依赖：`numpy`、`pyserial`（`parec` 用于抓取 PulseAudio/PipeWire 音频流）。

### 6.3 Windows 运行

```bat
pip install numpy pyserial sounddevice
python pc_audio_sender_win.py --port COM3
python pc_audio_sender_win.py --list          REM 查看音频设备
```

使用 WASAPI Loopback 采集扬声器输出。

### 6.4 串口协议（115200 8N1）

| 帧类型 | 格式 | 用途 |
|---|---|---|
| 频带帧 | `AA 55 01` + 64 字节（0~100）+ 校验 | 拾音器面板 |
| 波形帧 | `AA 55 02` + 128 字节左声道 + 128 字节右声道（int8）+ 校验 | 示波器 XY |

校验 = 所有数据字节之和 `& 0xFF`。

### 6.5 脚本音频处理

- 采集 48kHz → 重采样 8kHz（1024 点 FFT，分辨率 7.8Hz）；
- 64 个对数频带（40Hz~3.8kHz），dB 压缩 + 开方增强 + 噪声门；
- 波形：左右声道各 128 点，共同峰值归一化（保持 XY 比例）。

## 7. 构建与烧录

### 7.1 环境

ESP-IDF v5.4（工程 `~/esp/esp-idf`），每次新终端先执行：

```bash
. $HOME/esp/esp-idf/export.sh
```

### 7.2 构建与烧录

```bash
cd Demo2_wifi_time_clock
make build                 # 编译（等同 idf.py build）
make flash                 # 编译并烧录（串口自动探测）
make flash PORT=/dev/ttyACM0
make monitor               # 查看串口日志
```

Windows 下可用 ESP-IDF 的 `idf.py build flash -p COM3` 或 esptool 烧录。

> ⚠️ **烧录与日志必须走 UART 口（CH343）**。注意烧录前停止正在运行的电脑音频脚本（会占用串口）。

### 7.3 固件信息

- 目标：esp32s3，16MB Flash；
- 固件大小约 1.31MB（分区 1.5MB，剩余 15%）；
- 中文字库 24×26 点阵（4444 字：GB2312 符号区 + 一级汉字 + 常用扩展字），二进制嵌入。

## 8. 技术原理

### 8.1 显示驱动

- `LCD_CAM` 的 **i80 并行总线 + DMA** 输出颜色数据，GPIO 控制 LAT/OE/行地址；
- **RGB444 灰度（4 位/通道，4096 色）BCM 时间片调制**，全屏刷新约 200Hz；
- 双缓冲：渲染任务写后台缓冲，刷新任务帧边界切换，避免撕裂。

### 8.2 音频分析

- MAX9814 → ADC1 连续采样（8kHz，512 样本/帧）；
- 64 个对数频带用 **Goertzel 算法**计算（比完整 FFT 省资源）；
- 降噪链：80Hz 高通 → 自适应噪声底 → 噪声门 → 峰值归一化 → 平滑 → 静音检测。

### 8.3 中文显示

- UTF-8 解码 → Unicode 码点二分查找字库 → 24×26 点阵渲染；
- 字库支持 GB2312 符号区（全角标点）与一级汉字，扩展字在生成脚本中补充。

### 8.4 游戏 AI

- **俄罗斯方块**：枚举旋转×落点，El-Tetris 评分（消行/高度/空洞/凹凸）选最优；
- **贪吃蛇**：BFS 寻路到苹果，无路时选择安全方向；
- **Flappy Bird**：根据前方管道间隙中心决策扇翅时机，间隙 ±8px 平滑漂移；
- **坦克大战**：FC 风格砖块纹理 + 像素坦克，AI 自动走位/射击/保家；
- **吃豆人**：24×24 迷宫（DFS 生成、281 格全连通），16×14 视口相机跟随；
  幽灵按曼哈顿距离追击，撞到吃豆人时幽灵回巢（不重置整局）；
- **飞机大战**：玩家巡逻射击 + 威胁规避（躲避下落弹幕），敌机正弦摆动下降并
  开火，命中产生三段色爆炸粒子，游戏永不结束；
- **2D 赛车**：俯视公路滚动，玩家车自动变道躲避前方来车并超越，相撞时对方爆炸、
  玩家短暂无敌，顶部状态栏显示时间；

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 屏幕全黑 | 检查 5V 供电、共地；OE 极性见 `hub75.c` 的 `HUB75_OE_ACTIVE_LOW` |
| 屏幕很暗 | 管理页面调高亮度；或调大 `main.c` 中 `bcm_base_us` |
| 连热点打不开网页 | 手动访问 `http://192.168.4.1`；关闭手机移动数据 |
| 配网后回 SETUP | WiFi 密码错误/信号弱，重新配置（ESP32 只支持 2.4G） |
| 安静时拾音器乱跳 | 调低「拾音灵敏度」；检查 MAX9814 OUT 是否远离时钟线 |
| 电脑音频无反应 | 确认脚本运行、串口正确、表盘选的是拾音器/示波器 |
| 波形卡顿 | 检查串口波特率、脚本版本（新版每帧发送波形帧） |
| 烧录报 "端口被占用" | 停止正在运行的电脑音频脚本 |
| 时间不显示/不准 | SNTP 依赖 WiFi；检查时区（固定 UTC+8，可在 `net_time.c` 修改） |
| 想恢复出厂 | `make erase-flash` 后重新烧录 |
